# 开场故事的烘焙工具

新角色第一次进游戏时放的动态漫画（`js/story.js`）。画格不是手画的，也不是 AI 生成的：用游戏自己的引擎摆拍
（角色、区域、首领、特效都是游戏里现成的），渲染后在 CPU 上加一道漫画处理，烘成分层 webp 放在 `assets/story/<格>/<层>.webp`。
播放时只做 2D：各层视差、镜头慢推、2D 余烬 / 落灰 / 烟 / 雷、字幕。游戏本体不加载这个目录里的任何东西。

所有命令都会起 Chrome，必须走 `cc-slot pool`（本机规矩）。

## 文件
| 文件 | 用途 |
| --- | --- |
| `panels.mjs` | 每一格的摆拍：区域（`zone` / 余烛殿 `pin`，布局种子固定）、`setup`（在页面里执行：站位、动作帧、临时灯光、`window.__points` 记下给播放器用的世界坐标）、镜头 `cams`（`rel` 相对焦点 / 绝对 `pos`）、分层 `layers`、裁切比例 `aspect` |
| `ink.js` | 注入页面的烘焙库：按层显隐渲染（游戏自己的渲染链）、深度图、角色层的透明度（黑底 / 白底各渲一次）、漫画处理（墨线、平涂分阶、网点、纸面颗粒）、定格姿势 `pose`、关节位置 `jointPos` |
| `bake.mjs` | 烘焙：`node tools/story/bake.mjs [--panels p1,p6] [--try] [--debug] [--out 目录]`；`--try` 每个候选镜头出一张整图比构图；打印的 `points`（画面比例坐标）抄进 `js/story.js` 的 `glow` / 粒子范围 |
| `capture.mjs` | 在游戏页面里放故事、按时间点截图：`node tools/story/capture.mjs <目录> [--panels 0,5] [--sizes 1280x800,1024x640] [--strip 10] [--video 24] [--low]` |
| `posetest.mjs` | 调姿势：同一格的场景里套几组姿势各拍一张（关节标红点） |
| `explore.mjs` / `map.mjs` | 调构图：打印区域布局里的地标、按给的镜头拍几张 / 打印可走地图 |
| `common.mjs` | 起游戏（`test/harness.mjs`）、固定 `Math.random` 种子、停住模拟、镜头接管 |

## 重烘
角色、区域、首领的外观改了以后重烘一遍，图会跟着变（同一份代码、同一个种子出同样的画面）：
```
cc-slot pool <名字> shots -- node tools/story/bake.mjs --panels p6,p8,p5,p2a,p7a,p2b,p7b,p2c,p3,p7c,p1,p7d,p4
```
（按区域排序，少换几次区；`p7d` 给主角装上烬铸武器，放在用到主角的 0 区画格后面。）
要是镜头 / 站位动了，`bake.mjs` 打印的 `points` 和 `js/story.js` 里对应的 `glow` / `area` 要一起改。

## 注意
- 有首领的格（`bosses: [...]`，p4 / p7a–d）先 `need` 首领包、建好脚本生成的新模型（缺了就报错），摆拍和「`Math.random` 从按格子名定的种子重新开始」在同一次同步执行里；
  摆完把画面时钟定到 10（`W.debugTime`：发光圈的呼吸、水面、火光闪烁的相位和打开页面花了多久无关；按帧累加转角的首领环 / 护盾板停在静止角度）。这样同一份代码烘两次，webp 逐字节一样
  （T35 起；在这之前首领格拍到的是程序化的旧首领，两次烘出来的发光强度和姿势也不一样）。新模型没有 taunt / call / howl，姿势退到各自的蓄力定格。
- 布局种子固定（`G.debug.zoneSeed`），否则同一个区每次的布局都不一样。
- 游戏镜头的近裁面是 2 米，角色的蒙皮网格按绑定姿态做视锥剔除：`ink.js` 拍近景时把近裁面改成 0.1、关掉角色的剔除。
- 特效面片是按游戏镜头的朝向摆的：渲染前用拍摄镜头的朝向跑一次零时长的 `W.update(0)`。
- 漫画处理里发光的像素（熔岩、火、特效）不描墨线；烟、尘团这类普通混合的特效卡片（`hide: ['normalfx']`）和环境粒子（`'points'`）在近景里不拍，火星交给播放器的 2D 粒子。
