# 面板界面规范（UI-R）

所有页签共用的外壳和组件，B1 起用。新页面或改版的页面都按这里来，代码在 `js/ui.js`「UI-R 共用组件」一节和 `css/style.css` 末尾「UI-R B1」一节。

## 两种排法

| | 桌面（宽屏） | 窄屏 / 触屏 |
| --- | --- | --- |
| 条件 | 宽 > 900 且高 > 500 | `(max-width: 900px), (max-height: 500px)`，JS 里是 `compactUi()` |
| 页头 | 50 px，品牌字、按键角标 | 一行 36 px，没有品牌字 |
| 点按区 | 不强制 | 不小于 44×44（`--hit`） |
| 物品卡 | 单击后锚在格子旁边的浮卡 | 横屏从右侧滑出，竖屏从底部升起 |

竖屏是窄屏里画面宽 ≤ 600 的情况（`portraitUi()`）：页签只写一个字，`[?]` 挪进页面的工具栏。

旋转横屏（mobile-m2，竖着拿手机、画面转 90°，`html.t-rot`）：按宽度写的媒体查询要加 `:where(html:not(.t-rot))` 守卫；横屏专用的规则用 `html.t-land`（真横屏和旋转横屏都有）；高宽用 `var(--vh)` / `var(--vw)`；JS 里量位置用 `G.rectToFrame` / `G.viewW` / `G.viewH`（ui.js 的 `fRect` / `fW` / `fH`）。触屏的尺寸 token 写在 `html.touch-ui` 下：`--fs-xs` 11、`--fs-sm` 12、`--fs-base` 13、`--fs-md` 14、`--fs-lg` 16、`--head-h` 36、`--hit` 44。桌面的值等于原来的样子。最小字号 11 px。

## 规矩

- **一个页面状态里只有一个区域能纵向滚动**，DOM 上标 `data-list`。整页、整列一起滚都算不合格。
- **能点的东西盒子不小于 44×44**（触屏）：`button`、`[data-act]`、格子、页签。图标可以画小，盒子用透明内边距撑大。页头里的页签、`[?]`、`✕` 高 44 px，往下伸进正文的上边距（`margin-bottom: -8px`）。
- **安全区和圆角**：面板四周的内边距用 `--sa-t / --sa-r / --sa-b / --sa-l`（mobile-hotfix 给了最小边距），正文里的东西不要再贴着面板边。
- **说明只出现一次**：每页第一次打开时，底部一行显示一句；在这页里点了任何东西、离开这页或关掉面板以后不再自动出。之后点 `[?]` 看全部。「看过了」记在 localStorage 的 `cinder-abyss-ui-seen`，不进存档。说明写在 `PAGE_HINTS[页名]`，触屏、桌面各一套，触屏的不能有「右键 / 左键 / 悬停 / Alt / WASD / Shift」。

## 组件

| 名字 | 用法 |
| --- | --- |
| 页签 | `TABS` 里加一行 `[页名, 两个字, 按键, 一个字]`，`RENDER[页名]` 给渲染函数。按键在 `js/main.js` 的 `PANEL_KEYS` |
| `pageNote(页名, html, cls, keep, right)` | 页面底部那一行：一次性提示、新手提示、操作结果。`keep` 时窄屏上一直占位（内容换了页面不跳），`right` 放在右边（比如件数） |
| `helpBtn('in-page')` | 竖屏时放进页面工具栏的 `[?]`（页头的那个自动隐藏） |
| `sheetHtml({ head, body, acts, msg, cls })` | 卡片：头部固定，`body` 是唯一滚动区，`acts` 是底部 44 px 的操作条。位置由 `placeCard()` 和 css 定：整张卡片在页面正文里，不盖页头和页签；桌面上放在背包格外面（先左后右），太高就让中间那段滚动 |
| `ui.card` / `openCard()` / `closeCard()` / `clickItem()` | 物品卡的状态。点卡片外面、点 `✕`、再点同一件、Esc 都会收起；点另一件物品直接换内容 |
| `ui.pop` + `popHtml()` / `placePop()` | 锚在按钮下面的小菜单（`kind`：筛选、⋯、说明）。点外面收起；锚点按钮的 `data-act` 和 `kind` 同名，再点一次也收起 |

物品卡的操作条：「装备」是主按钮，放最左边、最宽。触屏上有任何按钮窄过 44 px 时，「丢弃」「锁定」收进「⋯」菜单（`placeCard()` 量完再排一次）。按钮一律不许被截断。

桌面单击物品要等 250 ms（`CARD_DELAY`）才开卡，这段时间里第二下点击算双击（穿上），开始拖动也不会开卡，所以不会闪一下。触屏是马上开，450 ms 内点同一格算点两下（穿上并收起卡片）。

## B4b 加的几处

- **拾烬客**：桌面两列不变（两列各是一个 `data-list`）。窄屏用子页签 货架 | 卖出 | 烛芯（`ui.trdView`），一行 46 px、行尾按钮 64×44 直接买卖，点一行出卡片：`ui.card = { trd: 'stock', i }` 或 `{ trd: 'sell', uid }`，由 `traderSheet()` 画，收起照常走 `closeCard()`。
- **标题画面矮屏**（画面高 ≤ 500，旋转横屏是 `html.t-rh500`）：标志缩成左边 64 px 的图标加字，菜单在右边排两列，「继续游戏」占一整行，页脚放到右下。角色页和职业选择占满整个高度，不显示标志和页脚。
- **职业选择、角色页（窄屏）**：`.m-view` 带 `cpt`，`m-body` 不滚，里面的卡片区滚。职业选择是一排五个职业标签加选中的那一张，「返回」只在底栏；角色卡 64 px，整张点一下就是「进入」，右边「删除」，「改选职业」挪到底下那一行。
- **主线追踪条**（触屏）：画面高 < 360 且按钮是 L 档、或者打起来时，收成一行（`#quest.t-q1`，只留目标）；点一下展开 3 秒，目标换成新的一步时也先展开 3 秒。逻辑在 `js/touch.js` 的 tick 里，和提示卡的「打起来收成一行」放在一起。
- **旁白卡和提示卡**（触屏）：旁白卡放着的几秒里提示卡让开（`visibility: hidden`），旁白卡用它的位置，放完提示卡回来。

## 测试

`test/ui-layout.mjs` 的 `uiLayoutCheck({ touch })` 在页面里跑，返回不合格项：

- a. 文字和点按目标都在视口里，只有 `data-list` 里滚得到的除外；
- b. 只有 `data-list` 能纵向溢出；
- c. 页面没有横向溢出；
- d. 触屏：页头 ≤ 36 px、字号 ≥ 11 px、点按区 ≥ 44×44；
- e. `elementFromPoint` 打到每个点按目标的中心，打到的是它自己（被打开着的卡片、小菜单盖住的不算）；
- f. 卡片和小菜单的操作条在视口里。

尺寸表是 `UI_SIZES`：触屏 844×340、667×320、734×338（用户真机）、1000×450、390×844，各跑一组 59 px 安全区和一组 0，再加一组旋转横屏 390×844；桌面 1920×1080、1366×768、1280×720。触屏横屏、安全区为 0 的那几组还查 iPhone 圆角（`test/corner-mask.mjs`）。

**加一个面板：** 在 `test/smoke.mjs` 的 `uiLayoutSteps` 里给 `UI_PANELS` 加一项 `{ name, states: [{ id, go }] }`，不在 `#panel` 里的（比如标题画面）再给 `check: { roots, head }`（量哪几块、哪个算页头）。所有面板跑完后 `uiLayoutDone()` 关掉两个浏览器。`go(驱动)` 把面板带到这个状态（打开页签、点开卡片、切子页签），步骤会在每个尺寸下跑一遍检查，卡片状态还会点外面验证能收起。
