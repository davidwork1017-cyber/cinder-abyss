# 面板界面规范（UI-R）

所有页签共用的外壳和组件，B1 起用。新页面或改版的页面都按这里来，代码在 `js/ui.js`「UI-R 共用组件」一节和 `css/style.css` 末尾「UI-R B1」一节。

## 两种排法

| | 桌面（宽屏） | 窄屏 / 触屏 |
| --- | --- | --- |
| 条件 | 宽 > 900 且高 > 500 | `(max-width: 900px), (max-height: 500px)`，JS 里是 `compactUi()` |
| 页头 | 50 px，品牌字、按键角标 | 一行 36 px，没有品牌字 |
| 点按区 | 不强制 | 不小于 44×44（`--hit`） |
| 物品卡 | 单击后锚在格子旁边的浮卡 | 横屏从右侧滑出，竖屏从底部升起 |

竖屏是窄屏里画面宽 ≤ 600 的情况（`portraitUi()`）：页签只写一个字，`[?]` 挪进页面的工具栏。

旋转横屏（mobile-m2，竖着拿手机、画面转 90°，`html.t-rot`）：按宽度写的媒体查询要加 `:where(html:not(.t-rot))` 守卫；横屏专用的规则用 `html.t-land`（真横屏和旋转横屏都有）；高宽用 `var(--vh)` / `var(--vw)`；JS 里量位置用 `G.rectToFrame` / `G.viewW` / `G.viewH`（ui.js 的 `fRect` / `fW` / `fH`）。触屏的尺寸 token 写在 `html.touch-ui` 下：`--fs-xs` 11、`--fs-sm` 12、`--fs-base` 13、`--fs-md` 14、`--fs-lg` 16、`--head-h` 36、`--hit` 44。桌面的值等于原来的样子。最小字号 11 px。

## 规矩

- **一个页面状态里只有一个区域能纵向滚动**，DOM 上标 `data-list`。整页、整列一起滚都算不合格。
- **能点的东西盒子不小于 44×44**（触屏）：`button`、`[data-act]`、格子、页签。图标可以画小，盒子用透明内边距撑大。页头里的页签、`[?]`、`✕` 高 44 px，往下伸进正文的上边距（`margin-bottom: -8px`）。
- **安全区和圆角**：面板四周的内边距用 `--sa-t / --sa-r / --sa-b / --sa-l`（mobile-hotfix 给了最小边距），正文里的东西不要再贴着面板边。
- **说明只出现一次**：每页第一次打开时，底部一行显示一句；在这页里点了任何东西、离开这页或关掉面板以后不再自动出。之后点 `[?]` 看全部。「看过了」记在 localStorage 的 `cinder-abyss-ui-seen`，不进存档。说明写在 `PAGE_HINTS[页名]`，触屏、桌面各一套，触屏的不能有「右键 / 左键 / 悬停 / Alt / WASD / Shift」。

## 组件

| 名字 | 用法 |
| --- | --- |
| 页签 | `TABS` 里加一行 `[页名, 两个字, 按键, 一个字]`，`RENDER[页名]` 给渲染函数。按键在 `js/main.js` 的 `PANEL_KEYS` |
| `pageNote(页名, html, cls, keep, right)` | 页面底部那一行：一次性提示、新手提示、操作结果。`keep` 时窄屏上一直占位（内容换了页面不跳），`right` 放在右边（比如件数） |
| `helpBtn('in-page')` | 竖屏时放进页面工具栏的 `[?]`（页头的那个自动隐藏） |
| `sheetHtml({ head, body, acts, msg, cls })` | 卡片：头部固定，`body` 是唯一滚动区，`acts` 是底部 44 px 的操作条。位置由 `placeCard()` 和 css 定：整张卡片在页面正文里，不盖页头和页签；桌面上放在背包格外面（先左后右），太高就让中间那段滚动 |
| `ui.card` / `openCard()` / `closeCard()` / `clickItem()` | 物品卡的状态。点卡片外面、点 `✕`、再点同一件、Esc 都会收起；点另一件物品直接换内容 |
| `ui.pop` + `popHtml()` / `placePop()` | 锚在按钮下面的小菜单（`kind`：筛选、⋯、说明）。点外面收起；锚点按钮的 `data-act` 和 `kind` 同名，再点一次也收起 |

物品卡的操作条：「装备」是主按钮，放最左边、最宽。触屏上有任何按钮窄过 44 px 时，「丢弃」「锁定」收进「⋯」菜单（`placeCard()` 量完再排一次）。按钮一律不许被截断。

天赋页（B3）的卡片也放在 `ui.card` 里：`{ tree: 'node', id }` 是节点卡，`{ tree: 'sum' }` 是汇总卡，点外面、`✕`、Esc 收起的规则和物品卡一样（`treeCard()`）。

桌面单击物品要等 250 ms（`CARD_DELAY`）才开卡，这段时间里第二下点击算双击（穿上），开始拖动也不会开卡，所以不会闪一下。触屏是马上开，450 ms 内点同一格算点两下（穿上并收起卡片）。

## 技能页（B2）

- **桌面**：技能栏在上；下面三栏：技能列表（360 px）| 选中的那张大卡片（就是原来的技能卡，一次一张，默认技能栏第一格）| 辅助宝石（拖到槽里）。点列表的一行或技能栏的一格换中间那张卡。技能图标从列表那一行或中间卡片拖进技能栏；辅助宝石从右栏拖进槽，拖回右栏取下。
- **窄屏 / 触屏**：技能栏一行 44 px（竖屏是 5 个 64 px 的方块），子页签 `技能 | 辅助 | 学习`，下面是 44 px 一行的列表（唯一滚动区）。点一行出技能卡（`.sheet.skc`，状态在 `ui.card = { sk }`）：头部是图标、名字、类型；中间先是 3 个辅助槽，再是说明、刻式、数值；操作条是「放到」大按钮 / 技能 1 / 技能 2（触屏不写键名）。「辅助」子页签点一行出辅助卡（`ui.card = { sup }`）：说明、镶在哪、「镶到」能用它的技能。「学习」子页签是无铭宝石和没学会的技能，没有无铭宝石时变暗。
- **选辅助**：点空槽，卡片中间那段换成辅助宝石列表（`#picker`，在卡片里，不是浮层），「返回」换回来。
- **Alt 详情**：窄屏卡片里是点开的「详情」折叠（`ui.foldAlt` 时 `altBox` 出 `<details>`），桌面照旧按住 Alt。
- `G.ui.open('skills', x)`：x 是子页签名（`skills` / `sup` / `learn`），或一行的键（技能 id / `G.BASIC_CARD` / `'wskill'`）：桌面选中它，窄屏开它的卡片。测试里用 `T.skCard(id)` / `T.skCards(f)` 拿卡片。

## 天赋盘的触屏默认视口（dev-48，随 B2）

触屏上这次打开游戏后第一次看天赋盘：以前沿（已点亮 + 能点亮）的外框中心为准放大一档；能点亮的每一个都要整个在盘面里、不压在点数 / 缩放 / 底部那一行下面，放不下就少放大一点（最多退回全览）；能点亮的彼此在屏幕上不到 44 px 而盘面还放得下时再放大。之后记住玩家自己的缩放和平移（`ui.tv`，只在内存里，不进存档），「全览」一下回去。桌面不变。测试用 `G.ui.treeViewReset()` / `G.ui.treeFront()`。

## 地图、帮助、设置（B4a）

- **地图**只做「去哪」：层级加区域卡片。桌面跟以前一样，卡片上直接点「进入」。窄屏上区域卡片排成一排横着滑（竖屏竖着滚），这一排就是 `data-list`。点卡片会出区域卡（`ui.zcard`，用 `sheetHtml` 做，「进入」在操作条上）；余烛殿是最后一张卡片。长按卡片照旧出浮窗。择印盖在地图上时，下面的内容放在 `.map-in[inert]` 里（`display: contents`，不影响排法）。渊印图例在 `[?]` 里。
- **帮助**：`HELP_TOPICS` 一行一个话题，`[id, 两个字, 渲染函数]`。左边是话题列（竖屏放在顶上一排横滑），右边只显示一个话题，一行最多 36 个字。`G.ui.open('help', id)` 直接打开某个话题。游戏里暂停菜单的「操作说明」打开的是「操作」这一节；标题画面打不开帮助页，那边还是只读的一页，用同一个按键表。
- **设置**（标题画面和暂停菜单共用 `menuSettings`）分六组：画面、操作、拾取、打击手感、声音、角色。宽度放得下两列时排两列（`columns: 2 300px`）。开关那一行整行是按钮，`data-tact` 和 `on` 都写在行上。拾取、画质、显示主线、「删除这个角色」原来在地图页，现在都在这里；删除只在暂停菜单里出现，流程和文字没变（`menu.delSelf`）。
- **横着滑的列表**：`overflow-x` 设成能滚，`overflow-y: hidden`，再标 `data-list`。布局检查对这种列表按高度判断「滚得到」。

## B4b 加的几处

- **拾烬客**：桌面两列不变（两列各是一个 `data-list`）。窄屏用子页签 货架 | 卖出 | 烛芯（`ui.trdView`），一行 46 px、行尾按钮 64×44 直接买卖，点一行出卡片：`ui.card = { trd: 'stock', i }` 或 `{ trd: 'sell', uid }`，由 `traderSheet()` 画，收起照常走 `closeCard()`。
- **标题画面矮屏**（画面高 ≤ 500，旋转横屏是 `html.t-rh500`）：标志缩成左边 64 px 的图标加字，菜单在右边排两列，「继续游戏」占一整行，页脚放到右下。角色页和职业选择占满整个高度，不显示标志和页脚。
- **职业选择、角色页（窄屏）**：`.m-view` 带 `cpt`，`m-body` 不滚，里面的卡片区滚。职业选择是一排五个职业标签加选中的那一张，「返回」只在底栏；角色卡 64 px，整张点一下就是「进入」，右边「删除」，「改选职业」挪到底下那一行。
- **主线追踪条**（触屏）：画面高 < 360 且按钮是 L 档、或者打起来时，收成一行（`#quest.t-q1`，只留目标）；点一下展开 3 秒，目标换成新的一步时也先展开 3 秒。逻辑在 `js/touch.js` 的 tick 里，和提示卡的「打起来收成一行」放在一起。
- **旁白卡和提示卡**（触屏）：旁白卡放着的几秒里提示卡让开（`visibility: hidden`），旁白卡用它的位置，放完提示卡回来。

## 测试

`test/ui-layout.mjs` 的 `uiLayoutCheck({ touch })` 在页面里跑，返回不合格项：

- a. 文字和点按目标都在视口里，只有 `data-list` 里滚得到的除外；
- b. 只有 `data-list` 能纵向溢出；
- c. 页面没有横向溢出；
- d. 触屏：页头 ≤ 36 px、字号 ≥ 11 px、点按区 ≥ 44×44；
- e. `elementFromPoint` 打到每个点按目标的中心，打到的是它自己（被打开着的卡片、小菜单盖住的不算）；
- f. 卡片和小菜单的操作条在视口里。

可以平移缩放的画布（天赋盘）标 `data-pan`，浮在画布上的按钮标 `data-float`：

- 被画布边裁掉的内容拖过去就看得见，a 不算它，e 也只查中心露在画布里的；
- 画布内容被 `data-float` 的按钮盖住，e 不算（拖开就点得到）。

画布本身还是要在视口里。全览时另有一项检查（smoke 的 `treeFitCheck`）：每个节点都整个在盘面里、点得到，画出来的名字不小于 11 px。

尺寸表是 `UI_SIZES`：触屏 844×340、667×320、734×338（用户真机）、1000×450、390×844，各跑一组 59 px 安全区和一组 0，再加一组旋转横屏 390×844；桌面 1920×1080、1366×768、1280×720。触屏横屏、安全区为 0 的那几组还查 iPhone 圆角（`test/corner-mask.mjs`）。

## 手机设备预设和主屏幕 App 视口（rot-safe）

用户在 iPhone 17 Pro 上玩：从主屏幕打开（standalone，状态栏 black-translucent），手机横着拿、锁着自动旋转，游戏在旋转横屏里。以后的手机检查默认按这台来，预设在 `test/devices.mjs`：

| 预设 | 竖着的屏幕 | 状态栏 | 底部横条 |
| --- | --- | --- | --- |
| `IPHONE_17_PRO`（默认，`MOBILE_DEFAULT`） | 402×874，@3x | 62 | 34 |
| `IPHONE_16` | 393×852 | 59 | 34 |
| `IPHONE_X` | 375×812 | 44 | 34 |

`standaloneContext(browser, 预设, { rot })` 开一个按真机模型模拟的 WebKit 配置。模型是两张用户截图（2026-11-24、2026-11-25）对出来的：

- 网页从屏幕最顶上画起，状态栏盖在上面；
- 布局视口少了状态栏那一截：`innerHeight`、`visualViewport.height`、`documentElement.clientHeight`、html 和 body 的 100% 高都是屏幕高减状态栏，`100vh` / `100lvh` 是整块屏幕高；
- 真正画出来的只到文档盒子的底边，再往下是黑的，fixed 的东西伸过去也会被裁掉。

所以旋转横屏在主屏幕 App 里这样摆（`js/touch.js` 的 `measure()`，只在这一处量）：html 撑到 `100lvh`（`html.t-stand`），body 改成 absolute，画面按 html 量出来的高摆；HUD 只放进 `visualViewport` 那一块，多出来的部分算进竖着的屏幕底边的安全区（`--t-cut`）。系统要是不让 html 长过布局视口，画面就按布局视口摆，底下留黑边，但 HUD 不会被裁。浏览器标签页里的旋转横屏照旧按 `innerHeight`。

真机上的数值在 设置 → 设备信息（只在触屏模式下有），截图就能对模型。检查在 `test/rot-standalone.mjs`，webkit 冒烟的「旋转横屏 · 主屏幕 App · 可见区」一步用它。

## 天赋页（B3）

- 桌面：盘面加侧栏，和以前一样；单击直接点亮、退回。图例和操作说明挪进 `[?]`，缩放按钮在盘面右下角竖排。
- 窄屏 / 触屏：盘面铺满正文。左上的「n 点可用」打开汇总卡，里面有支路进度、已获得的加成和重置；右下是 44 px 的缩放按钮，竖屏时横排；底部那一行浮在盘面左下，不挡点击。
- 触屏点节点出节点卡，按「点亮」才算，卡片留着可以接着点下一个，再点同一个就收起。点哪个节点按离手指最近算（`treePick`），点按区是屏幕上直径 44 px 的圆，看得见的部分不变。
- 卡片开着时盘面让开卡片：横屏让出右边，竖屏让出下面（`treeDock()`），整个盘面还看得见、点得到。
- 双指缩放：第二根手指落下就取消平移和长按（长按在 js/touch.js 里取消）。从第二根手指落下，到全部抬起后 400 ms，盘面上的点击都不算。
- 名字在屏幕上不到 11 px 时不画（窄屏全览时就是这样），放大一档就出来。

**加一个面板：** 在 `test/smoke.mjs` 的 `uiLayoutSteps` 里给 `UI_PANELS` 加一项 `{ name, states: [{ id, go }] }`，不在 `#panel` 里的（比如标题画面、暂停菜单）再给 `check: { roots, head }`（量哪几块、哪个算页头）。所有面板跑完后 `uiLayoutDone()` 关掉两个浏览器。`go(驱动)` 把面板带到这个状态（打开页签、点开卡片、切子页签），步骤会在每个尺寸下跑一遍检查，卡片状态还会点外面验证能收起。
